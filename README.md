# G. Marcondes | Soluções em TI (gmarcondes.tech)

Website institucional da **G. Morais Marcondes Soluções em Tecnologia da Informação LTDA**.

- **URL Oficial:** [https://gmarcondes.tech](https://gmarcondes.tech)
- **Instagram:** [@gmarcondes.tech](https://instagram.com/gmarcondes.tech)
- **Tech Stack:** Next.js 16 (App Router + Turbopack), React 19, Tailwind CSS v4, TypeScript.
- **i18n:** Suporte bilíngue nativo (Português / Inglês) com auto-detecção de localidade.

## 🚀 Como Executar Localmente

```bash
npm install
npm run dev
```

Abra [http://localhost:3002](http://localhost:3002) no navegador.

## 📦 Build e Exportação Estática (Cloudflare Pages)

```bash
npm run build
```

O diretório de saída estática é gerado em `/out`.
